Clés API

Conversation

Aucune IA ne garde la conversation en mémoire de son côté (aucun fournisseur — OpenAI, Anthropic, Google, Mistral — ne fait ça automatiquement ici) : à chaque message, l'app renvoie elle-même les N derniers messages définis ici, plus le prompt système. Si tes réponses précédentes sont longues (code, explications), le nombre de tokens d'entrée grimpe vite même avec peu de nouveaux messages — réduis ce curseur pour économiser.
Envoyé avant chaque message, sur tous les modèles. C'est aussi ce bloc de texte qui profite du cache de prompt Anthropic ci-dessous (voir explication).
🌐 Recherche web activée par défaut
S'applique aux nouvelles conversations (modifiable ensuite via 🛠️). Support variable selon le fournisseur.
⚠️ Ces outils de recherche web sont récents et évoluent régulièrement chez les fournisseurs : OpenAI (tool web_search, API Responses), Anthropic (tool bêta web_search_20250305), Google (grounding google_search, Gemini 2.0+). Mistral ne propose actuellement aucun outil natif de recherche web — la case sera ignorée pour ce fournisseur.

Cache de prompt (Anthropic)

Activer le cache du prompt système
Comment ça marche : sans "Prompt système personnalisé" rempli ci-dessus, il n'y a rien à mettre en cache et cette option n'aura aucun effet. Si tu remplis ce champ, ce texte sera envoyé une première fois normalement (légèrement plus cher : écriture cache), puis réutilisé à tarif très réduit pendant ~5 minutes tant qu'il reste identique (lecture cache) — utile si tu enchaînes plusieurs messages avec les mêmes instructions.

🎨 Génération d'image (bêta)

Seul OpenAI (DALL·E 3) est pris en charge pour l'instant. Anthropic et Mistral ne proposent aucune génération d'image, et l'intégration Google/Gemini n'est pas encore branchée ici. Active la case 🎨 dans le menu 🛠️ pour qu'un message génère une image au lieu d'une réponse texte (les pièces jointes sont alors ignorées).
